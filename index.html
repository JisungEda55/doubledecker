자료 출처와 검증 기준

이 지도는 나무위키의 「틀:2층버스 운행노선」 및 개별 노선 문서를 이용해 후보 노선과 정류장 명칭·정류소 번호를 정리합니다. 지도 표시는 HTML에 내장된 좌표만 사용하며 실행 중 정류장 대량 대조나 지오코딩을 하지 않습니다. 나무위키는 편집형 자료이므로 현행 운행 여부를 확정하는 공식 자료로 취급하지 않습니다.

  • 나무위키 미러: 2층버스 운행노선
  • 국토교통부 전국 버스정류장 위치정보 — 정류소 ID·명칭·WGS84 좌표의 기준 원장
  • 전국 정류장 위치정보 보존본 설명 — 2025-10-31 스냅샷 및 정류장별 조회 참조
  • 포천 3006 TAGO 경유 정류장 순서 및 개별 정류장 상세 페이지의 카카오맵 좌표 링크 — 포천 3006 양방향 정류소별 위치
  • OpenStreetMap — 배경 지도 및 도로 네트워크 데이터
  • Valhalla — 오픈소스 라우팅 엔진. costing=bus 버스 통행 프로파일 사용
  • FOSSGIS Valhalla 공개 서버 — API 키 없이 이용 가능하나 공정 사용 정책·요청 제한이 적용됩니다.
  • Valhalla Route API 문서 — 방문 순서가 고정된 다중 경유지 라우팅 및 버스 차량 제원
  • 현대자동차 일렉시티 이층버스 공식 제원 — 전장·전폭·전고 참고
  • 한국건설기술연구원 도로교통 자료 — 2층버스 차종별 제원 비교(일부 차종 전고 4.2m)

도로 경로 생성: 내장 좌표가 있는 정류장을 원래 순서대로 Valhalla route API에 전달하고 costing=bus로 도로 경로를 계산합니다. 중간 정류장은 경유점(through)으로 지정하여 입력된 정류장 순서를 바꾸지 않습니다. 일반 승용차 프로파일을 사용하지 않습니다. 비포장도로는 경로 중간에 포함되지 않도록 제외합니다. 라우팅 차량 제원은 국내 2층버스의 보수적 통행 가능 범위를 고려해 전고 4.20m, 전폭 2.50m, 전장 12.990m, 총중량 22.245t을 적용합니다. 이는 높이·폭이 큰 2층버스와 국내 2층 전기버스의 최대 전장·공표 총중량을 조합한 보수형 기준이며, 실제 운행 차량 한 모델의 단일 제원표와 동일하다는 뜻은 아닙니다. 현대 일렉시티 이층버스 공식 제원은 전장 12,990mm·전폭 2,490mm·전고 3,995mm이고, 별도 2층버스 비교 자료에는 전고 4,200mm 차종이 포함됩니다. Valhalla는 OSM에 기록된 버스 접근 및 차량 제한 태그를 바탕으로 계산하므로 태그가 누락되거나 오래된 도로는 제한 판단이 부정확할 수 있습니다. 이 경로는 해당 정류장 사이의 버스 통행 조건을 고려한 도로 경로이지, 운수사가 실제 인가·운행하는 공식 노선 형상 그 자체는 아닙니다. 공개 서버가 응답하지 않으면 직선 대체선을 그리지 않고 정류장 마커만 표시합니다. 반복 요청은 브라우저 저장소에 캐시하고 요청 간 간격을 둡니다.

좌표 내장 기준: 정류소 번호와 정류장명이 함께 일치하는 공개 전국 버스정류장 좌표와 TAGO 정류장 상세 페이지의 지도 좌표 링크를 각 S(정류장명, 정류소번호) 객체에 lat·lon으로 직접 내장했습니다. 숫자 ID만 일치하거나 같은 이름의 다른 승강장일 가능성이 있으면 좌표를 붙이지 않았습니다. 정적 좌표는 자료 수집 시점 이후의 정류장 이전·개편을 반영하지 않을 수 있습니다. 미확보 정류장은 외부 서비스로 검색하지 않으며 지도 마커를 생성하지 않습니다. 정류장 목록에서 좌표 미확보로 구분합니다.

현재 내장 데이터 범위: 조사 후보 87개 중 18개 노선에 632개 방향별 정류장 항목이 있습니다(상·하행 중복 포함). 현재 내장 좌표로 바로 표시되는 항목은 446개(고유 정류소 식별 조합 333개)이며, 좌표 미확보 항목은 186개(고유 식별 조합 139개)입니다. 좌표는 정류소 번호·명칭이 함께 일치하거나, 번호가 없을 때 전국 좌표표에서 명칭이 한 위치로만 확인되는 경우에만 정적으로 연결했습니다. 정류장 좌표가 없는 항목은 지도에 임의 위치로 표시하지 않습니다. 나머지 69개 노선은 나무위키 문서 자동 추출을 시도하는 미수집 항목입니다.

나무위키 문서 원문을 브라우저에서 읽을 때는 키 없는 Jina Reader 변환 경유를 시도합니다. 미러/프록시의 접근 정책이나 문서 형식 변경으로 실패할 수 있으며, 실패했다고 노선이 없다는 뜻은 아닙니다.
